# Источники: g9-logicheskie-operatsii-i-skhemy

Цели 9.4.2.1 «формулировать правила для логических операций: конъюнкция, дизъюнкция, инверсия», 9.4.2.2 «составлять логические выражения», 9.4.2.3 «строить логические схемы», 9.4.2.4 «строить таблицы истинности для логических выражений».
Название темы в `NIS_CS_2026_2027.json` («Логические операции и схемы») соответствует целям. В SB, TG и презентации используется старая цель «9.4.2.1 строить логические схемы и логические выражения» — содержание распределено по новым целям (см. `materials/map.md`, раздел 9.1B).

SB = `programs/Учебники/G9_Информатика_SB_RU учебник 2020.pdf`; TG = `programs/Учебники/G9_Информатика_TG_RU руков-во 2020.pdf`; презентация = `grade-9/9.1B_Логика/9 класс_ Лог сх и выраж.pptx`.
