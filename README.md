# NIS Computer Science Portal

Учебная платформа по информатике для 7–12 классов НИШ на Next.js (App Router) и Supabase.

## Основные возможности

- **Ученик**:
  - обучение и практика по темам программы (теория, презентации, проверка конспектов, практика, тематические экзамены, прогресс по целям обучения);
  - задания учителя и суммативное оценивание за раздел (СОР);
  - пробные экзамены (Paper 1–3) и интервальное повторение (`/repeat`);
  - личный кабинет, уведомления, поиск по материалам, настройки доступности (HCD).
- **Учитель**:
  - управление классами, учениками и видимостью тем;
  - создание и выдача заданий, экзаменов и СОР с живым мониторингом;
  - банк вопросов, проверка работ, аналитика успеваемости и экспорт в Excel.
- **Администратор**:
  - управление пользователями, классами, учебной программой, настройками и журналом аудита.

## Запуск локально

```bash
cp .env.example .env.local
npm install
npm run dev
```

## Проверки

```bash
npm test
npm run typecheck
npm run lint
npm run build
```
